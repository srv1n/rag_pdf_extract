# PDF-T-0011 · Paired baseline/candidate regression harness with per-document thresholds

## Intent

- What this is: a regression harness that runs a baseline build and a candidate build over the same corpus and reports per-document deltas, so any change can prove it didn't regress extraction quality.
- Why it matters: we fix documents one incident at a time; without paired runs a fix for one document can silently degrade twenty others. This is the discipline that makes every other robustness task in this epic safely landable.
- What "done" looks like: one command compares two revisions over the corpus and fails if any document regresses beyond a threshold, with a readable per-document report.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | A harness runs baseline and candidate against the same corpus revision and emits per-document metric deltas (character/word counts vs reference at minimum). | Inline verification (run output) |
| A2 | Missing predictions are failures, not skips. | Automated test or run output |
| A3 | A configurable per-document regression threshold fails the run when exceeded. | Run output on a synthetic regression |
| A4 | Adversarial fixtures (deep nesting, bombs, malformed containers) are part of the corpus and must not crash either build. | Run output |

## Non-goals

- No new golden-truth authoring beyond what the existing benchmark and eval material provides.
- No CI wiring in this task (follow-up once the harness is stable).
- No runtime dependency on an alternative PDF engine — an optional diagnostic probe using one is fine if trivially available.

## Implementation notes

- Build on the existing Supreme Court corpus harness (`benchmarks/`, commit b977077) and `bootstrap_benchmark.py`; extend rather than replace.
- Model: pdf-inspector's `docs/benchmarking.md` paired baseline/candidate design — same corpus+evaluator revision for both sides, per-document deltas, max-regression threshold.
- Reuse Poppler character counts already referenced in the repo as the independent reference where goldens are absent.
- Include the 13 historical failure documents if locatable; record corpus provenance in the harness README.
