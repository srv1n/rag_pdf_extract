# PDF-T-0013 · Port text-quality checks with multilingual recalibration

## Intent

- What this is: detectors for text that extracted "successfully" but is actually garbage — replacement characters, private-use glyphs, broken font-map artifacts, symbol soup, or cipher-like letter substitutions — feeding the garbled-text signal used for OCR fallback.
- Why it matters: silently garbled output is worse than an error; downstream RAG indexes it. We already measure decode quality; these checks catch classes our current metrics miss, and they must work on non-English documents without false alarms.
- What "done" looks like: quality assessment flags each garble class with page-level evidence, and clean multilingual documents (CJK, Arabic, Hebrew, Devanagari) are not flagged.

## Acceptance

| ID | Outcome | Proof |
|---|---|---|
| A1 | Quality metrics detect: replacement-char runs, private-use-area and C1-control density, broken-CMap artifacts, and symbol-dominant output, with page/span evidence. | Automated test |
| A2 | Substitution-cipher-like text detection exists and is gated so it cannot fire on non-Latin scripts. | Automated test |
| A3 | Clean fixtures in at least three non-Latin scripts produce zero garble flags. | Automated test |
| A4 | The flags feed the `suspected_garbled_text` reason of the per-page assessment (PDF-T-0009) when both have landed. | Inline verification |

## Non-goals

- No OCR triggering changes in this task — signals only.
- No language identification feature; only script-class gating for thresholds.

## Implementation notes

- Extend `src/quality.rs` (`DecodeQualityMetrics` / `assess_parse_quality` path) — do not create a parallel quality module.
- Reference: pdf-inspector `src/text_quality.rs` (MIT; retain attribution note). Its English-letter-frequency assumptions are the known hazard — every ported threshold needs a script-aware guard or multilingual calibration.
- Fixture sources: `vedanta.pdf` and the numbered corpus PDFs in repo root cover some scripts; generate or add small fixtures for the rest.
